# Real Mad Honey — Evening Ritual Lander

Static mobile-first landing page for Meta ads on the evening wind-down / alcohol-alternative angle.

## Preview locally

```bash
cd real-mad-honey
python3 -m http.server 8765
```

Open [http://127.0.0.1:8765/](http://127.0.0.1:8765/) on a phone or with DevTools at ~375px.

Or open `index.html` directly in a browser (video autoplay policies may differ on `file://`).

## What’s in this folder

| Path | Role |
|------|------|
| `index.html` | Lander markup (10 locked sections) |
| `styles.css` | Mobile-first styles |
| `script.js` | Sticky CTA, FAQ, reveal, video-in-view |
| `assets/` | Product/logo/harvest media + ad statics |
| `docs/ad-analysis.md` | Strategic analysis (A–J + message match) |
| `docs/assignment.md` | Distilled brief |
| `REASONING.md` | Six assignment questions |
| `AI-USAGE.md` | Tooling disclosure |
