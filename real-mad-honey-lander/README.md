# Real Mad Honey Lander

Static, mobile-first landing page for the alcohol-alternative / evening-ritual ad angle.

## Preview

```bash
cd real-mad-honey-lander
npx --yes serve -l 4173
```

Then open http://localhost:4173 — or simply open `index.html` in a browser.

## Buy CTAs

All Buy buttons link to: https://realmadhoney.com/products/mad-honey-us

## Structure

- `index.html` — single lander page
- `css/styles.css` — tokens, layout, motion
- `js/main.js` — sticky bar + scroll reveals
- `assets/` — product shots from realmadhoney.com + AI lifestyle images
